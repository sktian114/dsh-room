# dsh-room v0.3.16 · 首个公开发布

给 [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）桌面版加一个「联机」按钮：
房主开房，同一网络里的朋友用手机/另一台电脑输入 `IP:8787` 就能进房间，
看到成员、展开房主的工作区、一键打开房主的工作台——工作区就是房主的文件夹，
权限由房主的策略决定（封锁 / 只读 / 仅工作区可写 / 完全权限）。

> 原理一句话：房间代理把房客的浏览器请求改写成 loopback 再转给房主的 DSH，
> 于是 DSH 的 Host/Origin 栅栏永远看到 `127.0.0.1`，**不需要改 DSH 任何配置**。

## 安装

```bash
npm i -g @sktian114/dsh-room
node "$(npm root -g)/@sktian114/dsh-room/install.mjs"
```

Windows 上把最后一行换成
`node "$env:APPDATA\npm\node_modules\@sktian114\dsh-room\install.mjs"`。
装完**完全退出并重启 DSH**（托盘退出，不是关窗口），左侧栏出现「联机」即成功。

也可以直接用仓库里的一键脚本：`powershell -ExecutionPolicy Bypass -File .\install.ps1`。

## 这个版本里有什么

- **房间联机**：房主开房 → 生成邀请地址；访客浏览器直连，无需装 DSH。
- **四档权限**：工作区封锁 / 只读 / 仅工作区可写 / 完全权限，改小立刻生效。
- **会话共享**：访客在房主的工作区里建会话、发指令；工具审批只回房主。
- **房间聊天**：群列表 + 右侧横向面板，@ 点名唤醒 Agent，未读游标增量同步。
- **作者胶囊**：会话里每条指令上方有一行「小头像 + 昵称」，独占一行、正文在下一行，
  房主一眼知道是谁在说话（标记只认行首，代码块里的格式示例不会误伤）。
- **移动端**：手机浏览器可用，两级切换、面板 `100dvh` 限高、切后台自动重连。

## 安全（请务必读 [SECURITY.md](./SECURITY.md)）

- 能连上房间端口的人 = 组网内成员；房间口令只防误入，**不加密**。
- 访客在 DSH 眼里仍是 owner；插件靠**代理层**过滤 HTTP 信封、WS 帧和 `session/list`。
- 不要把 DSH 的 Web 端口直接暴露给访客，否则代理层的限制会被绕过。
- 本版本修掉发布前审计的两个阻塞项：
  - 分片 WebSocket 帧（`FIN=0`）绕过帧级过滤 → 可能拿到宿主终端流；现在解析层直接拒分片帧；
  - 每条消息复制 200KB 头像 → 单访客可打爆宿主内存与存档；现在消息头像压到 2KB、
    存档 48MB 硬上限 + 异步写、启动按上限截断。
- 另修：会话类端点不再采信请求体里的 `cwd`；房主端点增加 `Origin`/`Sec-Fetch-Site` 校验。

## 已知限制

- 0.3.x 预发布，接口与界面仍会变；未发布 LTS 分支。
- 停止房间不会撤销已下发的 DSH Cookie，要彻底断开需完全重启 DSH 或把人移出组网。
- 访客身份 id 由「昵称 + IP」派生：同 NAT 同名会被认成同一个人，改名后历史里的「我」会断成两个。
- 客户端每 1.5 秒会扫一遍文档找作者标记，长会话下有固定 CPU 开销（下轮优化）。
- 完整未修清单在 [`docs/audit-2026-10-25.md`](./docs/audit-2026-10-25.md)，每条都写了触发条件。
